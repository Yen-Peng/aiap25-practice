## Environment setup

Create and activate a Python 3.11 Conda environment:

```bash
conda create -n hotel-cancel python=3.11 -y
conda activate hotel-cancel
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the project

```bash
bash run.sh
```
